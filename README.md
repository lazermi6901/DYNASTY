# DYNASTY V1

Jeu idle médiéval/fantasy mobile.

## GitHub Pages
1. Dépose `index.html` et `manifest.webmanifest` à la racine du dépôt.
2. GitHub > Settings > Pages.
3. Source : Deploy from a branch.
4. Branche : main / root.
5. Ouvre l'adresse GitHub Pages depuis Safari sur iPhone.

La sauvegarde est locale au navigateur.
